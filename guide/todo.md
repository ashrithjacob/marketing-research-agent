- **The checklist.** The statics writer receives the avatar's stage and must use
  that stage's elements, every lower stage's too:
  1. claim: a big, direct promise
  2. amplifier: faster, bigger, easier, or "without" a downside
  3. mechanism: how it works, simply
  4. proof: UGC, testimonials, customer counts, before and afters,
     demonstrations, experts, studies, celebrities
  5. identity: challenge the belief "I'm the problem"; "it's not your fault"
- **Checkable.** Code can check a draft against the checklist the same way the
  stage is checked: the writer tags which elements each draft uses, from the
  closed list.
